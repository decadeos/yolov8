# Описание расчета расстояния до объекта

---

#### 1. Калибровка

Для каждой камеры необходимо вычислить константу `K_value`. 

$$ K_{value} = Z * \sqrt{darkpixels} $$

Где `Z` - известное расстояние до объекта,  `dark_pixels` - количество темных пикселей внутри рамки.

Для калибровки необходимо сделать фото объекта с известного расстояния. Запуск:

```bash
python detect_distance.py \
  --source src/camera_config/50.png \
  --weights runs/train/v6_mixup-cp/weights/best.pt \
  --calibrate \
  --ref-dist 50
```
Где `--source src/camera_config/50.png` - исходное фото, `--calibrate` - режим калибровки для расчета `K_value` (используется 1 раз), `--ref-dist` - известное расстояние.

Переменная `K_value` расчитается и сохраниться в `src/camera_config/utils.json`.


#### 2. Рабочий режим

Обычный запуск - над рамкой будет выводиться расстояние до oбъекта:

```bash
python detect_distance.py \
    --source test_videos/test.mp4 \
    --weights runs/train/v6_mixup-cp/weights/best.pt
```


#### 3. Расчеты

Для каждого кадра вычисляется количество темных и светлых пикселей. Это нужно, потому что при детекции мелких объектов рамка охватывает не только объект, но и пустую площадь рядом.

Эмпирически выяснено, что до `threshold_dark=12` (количество черных пикселей) нет смысла мерять дистанцию, так как значения скачут. Дистанции будет присвоено значение `-1`.
После вычисляется `K_value` и расстояние. Формула расстояния:

$$ dist = \frac{K}{\sqrt{darkpixels}} $$

> Вычисление черных пикселей в рамке делалось методом ОЦУ : [wiki](https://ru.wikipedia.org/wiki/%D0%9C%D0%B5%D1%82%D0%BE%D0%B4_%D0%9E%D1%86%D1%83)
